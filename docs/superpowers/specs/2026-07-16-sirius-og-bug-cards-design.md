# Карточки задач для Sirius OG

## Цель

Создать в ветке `sirius-og-buggy` отдельную Markdown-карточку для каждой из
54 строк `bugs_cards/sympy_og_tickets.csv`. Карточки предназначены для
школьника или агента, который должен воспроизвести и исправить баг без доступа
к готовому патчу.

## Результат

В каталоге `bugs_cards/` появятся 54 файла с именами вида
`01_sympy__sympy-14711.md`. Номер соответствует порядку строки в CSV, а остаток
имени — `instance_id`. Существующие CSV и `template.md` не изменяются.

## Содержимое карточки

Каждый файл следует структуре `bugs_cards/template.md` и содержит:

- номер, короткое русское название и точный `instance_id`;
- исходный `ticket_description` из CSV без пересказа;
- краткое русское объяснение пользовательского сценария и сути ошибки;
- ожидаемое исправленное поведение;
- самодостаточную команду ручного воспроизведения в `sirius-og-buggy`;
- наблюдаемое ошибочное поведение;
- точный селектор проверки из `sirius_tests/test_sympy_og_bugs.py`;
- производственные файлы из поля `patch_files`.

Готовые исправления, фрагменты `patch` и подсказки, раскрывающие реализацию
решения, в карточки не переносятся.

## Источники данных

- Порядок, ID, исходный текст, заголовок и пути берутся из
  `bugs_cards/sympy_og_tickets.csv`.
- Имена проверок и минимальные сценарии сверяются с
  `sirius_tests/test_sympy_og_bugs.py`.
- Формат и команды берутся из `bugs_cards/template.md` в целевой ветке.

Если в исходном тексте нет готового минимального примера, команда
воспроизведения строится по соответствующей учебной проверке. Если одна задача
имеет несколько проверок, в карточке перечисляются все относящиеся к ней
селекторы.

## Проверка результата

После создания выполняются следующие проверки:

- создано ровно 54 карточки и все 54 `instance_id` уникальны;
- порядок и имена файлов совпадают с порядком CSV;
- в карточках нет текста-заглушек из шаблона;
- каждый ID, тест и путь к коду существует в исходных файлах;
- исходный `ticket_description` перенесён без изменений;
- Markdown не содержит незакрытых блоков кода;
- изменены только новые карточки и эта спецификация.

Запуск полного набора тестов SymPy не требуется: задача меняет только
документацию. Для проверки команд воспроизведения достаточно синтаксической
проверки и сверки с уже существующими учебными тестами.
